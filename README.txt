# COUNSEL'S COUNCIL — Website

## Files
- `index.html` — complete website
- `style.css` — responsive styling and animations
- `assets/logo.png` — supplied logo
- `assets/hero-bg.png` — cropped background derived from the supplied website reference

## Run locally
Open `index.html` directly in Chrome/Safari, or use VS Code + Live Server.

## Important before publishing
1. Verify the office address. The supplied HTML and the supplied visual reference contain different addresses; this version keeps the address from the supplied HTML.
2. The enquiry form currently uses `mailto:`. For reliable production enquiries, connect it to Formspree, Web3Forms, FormSubmit, Netlify Forms, or your hosting provider's form handler.
3. Replace the Google Maps query with the firm's exact pin/address if needed.
4. Upload the entire folder to your hosting provider while preserving the `assets` folder.
